# games

Put your own dump of *Saturn Bomberman* here (USA, Europe or Japan, also the Japanese demo; cue/bin, ISO + WAV or CHD; subfolders are fine).
The launcher lists this folder by default. Nothing in it is committed, and after **Build & Play** the game plays
from its own copy in `recompiled/`, so the dump is no longer needed.
